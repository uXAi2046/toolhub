Security Warning

                        
JWTs are Base64Url encoded, not encrypted. Do not store sensitive information like passwords in the payload unless you encrypt the token itself (JWE).

                    

                

            


            
            

                
                

                    
About this tool

                    
This JWT Decoder allows you to decode JSON Web Tokens to inspect their headers and payloads. It helps in debugging authentication issues by verifying claim values and expiration times.
