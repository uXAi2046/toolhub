关于此工具

HTML 清理工具旨在模拟现代 Web 应用程序如何清理和净化用户提交的 HTML 内容。它帮助开发者和内容管理人员了解哪些 HTML 标签和属性被保留，哪些因安全原因被移除。

HTML 清理是一个关键的安全过程，通过移除潜在的恶意代码——如 <script> 标签、onclick 事件处理程序和不安全的 iframe 来源——来防止跨站脚本（XSS）攻击，同时保留安全的格式，如粗体文本、列表和链接。

常见允许的标签

  • 格式：<b>, <i>, <strong>, <em>
  • 结构：<p>, <div>, <span>, <br>
  • 列表：<ul>, <ol>, <li>
  • 链接：<a href="...">（通常具有限制的协议）
