安全警告

                        
JWT 是 Base64Url 编码的，而不是加密的。除非您加密令牌本身（JWE），否则不要在载荷中存储密码等敏感信息。

                    

                

            


            

                

                    
关于此工具

                    
这个 JWT 解码器允许您解码 JSON Web Token 以检查其标头和载荷。它通过验证声明值和过期时间来帮助调试身份验证问题。
