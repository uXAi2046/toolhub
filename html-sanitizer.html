About this tool

The Paste HTML Subset tool is designed to simulate how modern web applications clean and sanitize user-submitted HTML content. It helps developers and content managers understand which HTML tags and attributes are preserved and which are stripped out for security reasons.

HTML sanitization is a critical security process that prevents Cross-Site Scripting (XSS) attacks by removing potentially malicious code—such as <script> tags, onclick event handlers, and unsafe iframe sources—while preserving safe formatting like bold text, lists, and links.

Commonly Allowed Tags

  • Formatting: <b>, <i>, <strong>, <em>
  • Structure: <p>, <div>, <span>, <br>
  • Lists: <ul>, <ol>, <li>
  • Links: <a href="..."> (often with restricted protocols)
